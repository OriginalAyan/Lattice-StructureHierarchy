Structure Hierarchy

Tools → Structure Analysis → Structure Hierarchy, or the command hierarchy.

Lists every open atomic model as a tree: model → chains → residues (name + number) → atoms. Ligands are green, ions orange, water grey.

Selecting

  • Click, Ctrl-click or Shift-click rows. The matching atoms become the ChimeraX selection, so every command and mouse mode works on them.
  • Selecting atoms in the 3D window highlights and reveals them in the tree (untick "Follow 3D selection" to stop the tree expanding).
  • Double-click zooms to a row. Right-click for show/hide, Color, Label, Important marks, select within a distance, and Delete.

Row buttons

  • Check box (left): show or hide that model, chain, residue or atom.
  • Star (next to the check box, residues and atoms): mark as Important. "Important only" lists just the starred items.
  • ✕ (right end): delete the row (or the whole selection if the row is part of it). Undo with Ctrl+Z.

Searching

The tree filters as you type. Separate several residues with a comma: pro6, pro9. Residue name, number, chain and atom names are searched: 101, pro101, A:101, hoh, ca.

Select within a distance

Choose the radius (Å) and residues or atoms, then press the button; tick "live" to follow your selection.

Important marks and files

Marks are saved as REMARK 777 HIERARCHY-IMPORTANT header lines in PDB/PDBQT files and restored when the file is opened. To add them to an existing file (for example docking poses): hierarchy marks poses.pdbqt #1 or "Write ★ to file…".

Commands

hierarchy [show|hide|refresh] [search text]
hierarchy marks file [model]
